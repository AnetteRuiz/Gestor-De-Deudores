# Debt Manager (Backend)

A web application developed as a university team project to manage personal debts and payments. 

The application allows users to:

- Register multiple debtors with individual debt amounts.
- Track partial payments and see remaining balances.
- Export records to Excel for better visualization and control.

## Technologies Used

- Python
- Flask
- MySQL

## My Contribution

In this team project, I was responsible for:

- Backend logic using Flask (routes, controllers, validations).
- Database modeling and query handling.
- Implementing Excel report generation.
- Structuring the logic for adding, editing, deleting debtors and payments.
